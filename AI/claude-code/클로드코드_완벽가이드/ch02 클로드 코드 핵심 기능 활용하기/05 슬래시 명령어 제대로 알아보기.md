# 콘텍스트를 정리하는 `/compact`

- Pro, Max 플랜 모두 200K의 콘텍스트 윈도우 제공. 
- 클코와 대화 길어질 경우 윈도우 한계치가 넘어가며 새로운 정보 수용 불가.
- 이 때, /compact 명령어로 콘텍스트 요약해서 중요한 내용만 콘텍스트로 남김.
- 200k 윈도우 크기 넘어가면 자동으로 auto compact 실행되지만, **직접 /compact 명령어로 요약하는 것을 권장.**
    - 언제? **_다음 요청이 지금까지 요청고 다르거나 현재까지 중요한 내용이 잘 기억되면 좋을 때._**

# 자동 실행에 대한 권한 설정 `/permissions`

- 클로드 코드에 숙련될수록, 허락하는 과정이 귀찮아짐.
- 스코프별 권한 파일 위치 
  - 프로젝트 단위: `.claude/settings.local.json`
  - 사용자 단위: `~/.claude/settings.json`
- 예시
  - 현재 위치의 파일 및 폴더를 보여주는 ls 기능 허가
    - `/permissions` > Allow > Add a new rule > `Bash(ls:*)` > (Where should this rule be saved?) > `User Settings`


# 클로드 코드 메모리 관리 `/memory`

- 프로젝트 단위 메모리 관리: `./CLAUDE.md`
- 전역으로 메모리 관리: `~/.claude/CLAUDE.md`
- `/memory` 명령어로 메모리 파일 관리 가능


# MCP 관리 `/mcp`

- 연결한 MCP를 관리하고 관련 명령어 실행 가능.

# 기타 명령어

- `/bug`
- `/clear`
- `/cost`
- `/doctor`: 클로드 코드 설치 상태 확인
- `/help`
- `/login`
- `/logout`

- `usage`: 사용량 조회
