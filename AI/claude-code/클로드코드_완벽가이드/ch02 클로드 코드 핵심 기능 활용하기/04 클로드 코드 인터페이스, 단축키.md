## 클코 단축키 

- ctrl + c: 현재 입력 또는 클로드의 현재 생성 중인 아웃풋 중단
- ctrl + d: 클코 세션 종료
- ctrl + l: 클코 대화 유지. 사용자 대화창 입력 전부 삭제
- 위/아래 방향키: 기존에 실행했던 메시지 조회. 
- esc + esc: 직전 메시지로 회귀. 해당 메시지 보내기 직전으로 클로드와의 대화를 포크하는 효과.
- \ + enter: 메시지 창에서 줄바꿈. 모든 터미널에서 사용 가능.
- optional + enter: 메시지 창에서 줄바꿈. macOS 기본 세팅.
- shift + enter: /terminal-setup 명령어 실행 후 shift+enter로 줄바꿈.
- `# [메시지]`: CLAUDE.md에 빠르게 기억해야 할 요소를 추가하는 명령어
- `/ [명령어]`: 슬래시 명령어 실행
