# 02. 테스트 코드는 무엇이고 왜 필요한가?

- 테스트: 무언가를 검사한다.
- 코드: 프로그래밍 코드
- 테스트 코드: 프로그래밍 코드를 사용해 무엇인가를 검사한다.
  - 👉 자동으로 (사람의 손을 거치지 않고) 테스트할 수 있다.

## 테스트 코드는 왜 필요한가? 

- 개발 과정에서 문제를 미리 발견할 수 있다.
- 기능 추가와 리팩토링을 안심하고 할 수 있다.
- 빠른 시간 내 코드의 동작 방식과 결과를 확인할 수 있다. 
- 좋은 테스트 코드를 작성하려고 하다보면, 자연스럽게 좋은 코드가 만들어진다.
- 잘 작성한 테스트는 문서 역할을 돕는다. (코드 리뷰를 돕는 효과도 있다.)

### 쉽게 말해, 눈물을 흘리지 않기 위해 테스트 코드를 작성해야합니다.

- 개발하다보면 눈물을 흘려야할 때가..

- 그런데 기획자가 와서 새로운 기능이 필요하다고 한다.
  - 문제는 새로운 기능을 구현하려면 기능 1에 대한 수정이 필요한 것!
- 기능 1을 고치는데 이것을 의존했던 다른 기능이 전부 고장나버린다 ㅠㅠ
- 25개의 API를 모두 사람이 확인하려면 눈물이 난다 ㅠㅠ

![img_1.png](images/img_1.png)

- 최초 개발자가 아닌, 다른 개발자가 수정할 때 버그를 막기 위해서도 테스트 코드가 필요
  - 즉, 협업을 잘 하기 위해서도 테스트가 필요하다!

![img_2.png](images/img_2.png)

- 리팩토링을 안 하면 코드 복잡도가 올라가면서 유지보수 비용이 기하급수적으로 높아지고, 
  - 새로운 기능 추가가 느려지므로 비즈니스 생산성이 떨어진다.
- 사람이 수동으로 리팩토링의 영향을 확인한다면 눈물이 난다.
