```
User <-> JavaUserLoanHistory: 양방향 일대다 매핑(cascade)
User <- UserLoanHistory(코틀린): 다대일 양방향 매핑
```

- 이 상태에서 userRepository.deleteAll()을 이용하면, JavaUserLoanHistory 데이터는 삭제되지만, UserLoanHistory 데이터는 삭제되지 않는다.
