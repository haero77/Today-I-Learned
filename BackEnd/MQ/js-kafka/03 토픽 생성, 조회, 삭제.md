# Kafka Topic 생성, 조회, 삭제

## Kafka CLI란?

**Kafka CLI를 사용하면 Spring Boot 코드 없이 Kafka를 직접 조작할 수 있다.**

CLI는 `Command Line Interface`의 약자다. 터미널에 명령어를 입력해 Topic을 생성하거나 조회하고 삭제할 수 있다.

이 문서에서는 Kafka를 Docker로 실행하고 있다. 따라서 로컬 Kafka 디렉터리로 이동하지 않는다. `docker exec`로 Kafka 컨테이너 안의 CLI를 실행한다.

```text
터미널
  └─ docker exec
       └─ Kafka 컨테이너
            └─ kafka-topics.sh
```

## 사전 확인

**CLI를 사용하기 전에 Kafka 컨테이너가 실행 중인지 확인한다.**

```bash
docker compose -f compose.yml ps
```

`kafka`가 `healthy` 상태여야 한다. 실행 중이 아니라면 다음 명령어로 시작한다.

```bash
docker compose -f compose.yml up -d
```

## kafka-topics.sh란?

**`kafka-topics.sh`는 Topic을 관리하는 Kafka CLI 도구다.**

컨테이너 안의 실행 경로는 다음과 같다.

```text
/opt/kafka/bin/kafka-topics.sh
```

기본 명령어 구조는 다음과 같다.

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  <실행할 명령>
```

- `docker exec kafka`: 실행 중인 `kafka` 컨테이너에서 명령어를 실행한다.
- `/opt/kafka/bin/kafka-topics.sh`: Topic 관리 CLI를 실행한다.
- `--bootstrap-server localhost:9092`: Kafka에 처음 접속할 주소를 지정한다.

여기서 `localhost:9092`는 Kafka 컨테이너 내부에서 자기 자신에게 접속하는 주소다.

## 1. Topic 생성

**`email.send` Topic을 생성한다.**

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create \
  --topic email.send
```

명령어가 성공하면 다음 메시지가 출력된다.

```text
Created topic email.send.
```

다음 경고가 함께 출력될 수 있다.

```text
WARNING: Due to limitations in metric names, topics with a period ('.') or underscore ('_') could collide.
```

**이 경고는 Topic 생성 실패가 아니다.** `Created topic email.send.`가 출력됐으므로 Topic은 정상적으로 생성됐다.

Kafka의 메트릭 이름에서는 `.`과 `_`가 같은 문자처럼 변환될 수 있다. 예를 들어 다음 두 Topic은 서로 다른 Topic이지만 메트릭 이름이 충돌할 수 있다.

```text
email.send
email_send
```

한 Kafka 클러스터에서는 `.`과 `_`를 섞어 사용하지 않아야 한다. 이 문서에서는 강의 예제에 맞춰 `email.send`를 사용한다. 새 프로젝트의 규칙을 직접 정한다면 충돌을 피하기 쉬운 하이픈 형식도 사용할 수 있다.

```text
email-send
```

옵션의 의미는 다음과 같다.

- `--create`: Topic을 생성한다.
- `--topic email.send`: 생성할 Topic 이름을 지정한다.

이미 같은 이름의 Topic이 있으면 오류가 발생한다. 없을 때만 생성하려면 `--if-not-exists`를 추가한다.

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create \
  --if-not-exists \
  --topic email.send
```

## 2. 전체 Topic 조회

**Kafka에 생성된 모든 Topic 이름을 조회한다.**

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --list
```

앞에서 생성한 Topic이 있으면 다음과 같이 출력된다.

```text
email.send
```

## 3. 특정 Topic의 세부 정보 조회

**`--describe`를 사용하면 Topic의 Partition과 Replica 정보를 확인할 수 있다.**

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --describe \
  --topic email.send
```

다음과 비슷한 정보가 출력된다.

```text
Topic: email.send  PartitionCount: 1  ReplicationFactor: 1
Topic: email.send  Partition: 0  Leader: 1  Replicas: 1  Isr: 1
```

지금은 다음 두 가지만 확인하면 된다.

- `PartitionCount: 1`: Topic이 하나의 Partition으로 구성되어 있다.
- `ReplicationFactor: 1`: 이벤트를 한 개의 Broker에 저장한다.

`Leader`, `Replicas`, `Isr`는 Kafka의 Partition과 복제를 공부할 때 자세히 다룬다.

## 4. Topic 삭제

**`--delete`를 사용하면 Topic과 그 안의 이벤트를 삭제한다.**

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --delete \
  --topic email.send
```

Topic 삭제는 되돌릴 수 없다. 운영 환경에서는 Topic 이름을 다시 확인한 뒤 실행해야 한다.

## 5. 삭제 결과 확인

**전체 Topic 목록을 다시 조회해 삭제 여부를 확인한다.**

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --list
```

목록에 `email.send`가 없다면 정상적으로 삭제된 것이다.

## Kafka UI에서 확인

**CLI로 실행한 결과는 Kafka UI에서도 확인할 수 있다.**

브라우저에서 [http://localhost:8080](http://localhost:8080)에 접속한다.

```text
local 클러스터 → Topics
```

Topic을 생성하거나 삭제한 뒤 화면을 새로 고치면 변경 결과를 확인할 수 있다.

Kafka UI에서도 Topic을 생성하고 삭제할 수 있다. 하지만 Kafka의 기본 명령어를 익히기 위해 먼저 CLI로 실습한다.

## 전체 명령어 정리

### 생성

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create \
  --topic email.send
```

### 전체 조회

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --list
```

### 세부 정보 조회

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --describe \
  --topic email.send
```

### 삭제

```bash
docker exec kafka /opt/kafka/bin/kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --delete \
  --topic email.send
```
