# 1. 경력직 이직 프로세스 이해

## 2. 이직의 타이밍

- 회사 다닐 때는 회사 업무에 집중하자.
  - 8시간 근무하고, 퇴근 후에 준비하면 된다.
- 신입이 아니고 경력직이기 때문에 저희가 면접에서 많은 것을 요구하지 않는다. 
- 경력직에게 요구하는 것
  - 본인의 업무.
  - 회사에서 연차별로 바라는 것.
