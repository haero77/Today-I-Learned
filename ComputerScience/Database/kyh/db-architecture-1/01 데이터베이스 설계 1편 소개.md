# 1. 데이터베이스 1편 소개

- 누군가 개발 과정 중에서 가장 중요한 한 가지를 뽑으라고 질문한다면 데이터베이스 설계를 뽑음.
- 모든 것은 데이터베이스 설계 위에 세워지고, 유지보수에 가장 큰 영향을 미침.
- 문제는 이론으로 배운 내용과 현대의 데이터베이스 설계 사이에는 큰 괴리가 존재.
  - 데이터베이스 이론대로 설계했는데 문제가 생김.
- 이 강의를 통해 얻게 되는 것
  - 명확하고 현대적인 설계 방법
  - 변화에 유연하게 대처하는 최신 설계 방법
  - 실무 데이터베이스 설계 능력

## 학습 내용

- 체계적 설계: 개념적 -> 논리적 -> 물리적 모델링의 3단계 접근
- 실무 중심: 이론과 실습을 병행, 실제 쇼핑몰 프로젝트를 통한 실무 역량 강화
- 현대적 기법: 최신 데이터베이스 설계 트렌드와 실전 노하우

## 학습 순서

1. 개념적 모델링 요구사항 분석
   - 엔티티, 속성, 식별자 분류
   - 관계와 카디널리티
   - ERD 작성
   - 용어 사전
   - (실습): 실전 쇼핑몰 실습 개념적 모델링
2. 논리적 모델링 다양한 키 설계
   - 자연 키 VS 대리 키
   - 식별 VS 비식별 관계
   - 일대다, 일대일, 다대다 관계 설계
   - 정규화
   - (실습): 실전 쇼핑몰 실습 논리적 모델링
3. 물리적 모델링 실무 테이블 변환 규칙
   - 인덱스 설계
   - 역정규화
   - 테이블 정의서
   - 물리적 테이블 생성(DDL)
   - (실습): 실전 쇼핑몰 실습 물리적 모델링
