# 조인

## 조인이란 무엇인가?

- 조인은 두 개 이상의 테이블을 특정 컬럼을 기준으로 연결하여, 마치 처음부터 하나의 테이블이었던 것처럼 보여주는 기능

 
## 조인이 왜 필요한가?

- **_JOIN은 정규화를 통해 의도적으로 분리해 둔 테이블들을 다시 연결하여, 사용자가 원하는 형태의 데이터를 만들기 위해 필요합니다._**

---

- 한 마디로 요약하면, **_여러 테이블에 흩어져있는 데이터를 하나로 합쳐서 보기 위함이다._**
- 예를 들어, 쇼핑몰 도메인이 있고, 유저가 상품을 주문하면 주문 테이블에 데이터가 저장된다고 하자.
- 이렇게 데이터가 나뉘어져 저장되는 상황에서, 백오피스 요구사항 중, 주문에 대해 주문한 고객의 이름과 주문한 상품명을 한 화면에서 보고 싶다는 요구사항이 발생했다고 하자.
- 그런데, 고객의 이름과 상품명은 각각 유저 테이블과 상품 테이블에 저장되어있고, 주문 테이블에는 고객의 아이디와 상품의 아이디만 저장되어있다.
- 이 때, 고객명, 상품명을 한 번에 보기 위한 요구사항을 만족하기 위해서는 조인이 필요하다. 


## 정규화를 왜 하는가? 정규화를 하지 않으면 무슨 문제가 발생하는가?

- 정규화는 테이블을 올바르게 분리하여 데이터의 중복을 없애고, 데이터 불일치 위험을 원천적으로 막기 위해 합니다. 
- 만약 정규화를 하지 않고 하나의 테이블에 모든 데이터를 저장하면, 
  - 똑같은 정보가 여러 번 저장되는 데이터 중복이 발생합니다. 
  - 이로 인해 데이터를 수정, 삽입, 삭제할 때 일부 데이터가 누락되거나 의도치 않은 정보까지 삭제되는 **이상 현상(Anomaly)** 이 발생하여 데이터의 일관성이 깨지게 됩니다. 
  - 정규화는 이러한 이상 현상을 방지하기 위한 필수적인 설계 과정입니다.
