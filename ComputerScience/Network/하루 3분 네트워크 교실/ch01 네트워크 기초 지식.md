# 01 네트워크란? 

# 02 네트워크의 장점

> - **리소스를 공유**하는 것이 네트워크의 장점.
>   - 데이터를 주고받음으로써 리소스를 공유한다.

## 컴퓨터 네트워크란?

- 컴퓨터 네트워크
  - 컴퓨터와 컴퓨터가 그물망처럼 통신 매체로 연결되어서 데이터를 운반하는 것
- 컴퓨터 네트워크는 컴퓨터, 통신 매체, 데이터를 이용하여 구성됨. 
- 통신 매체 
  - 케이블, 무선 ....
    
## 네트워크를 사용하는 이유

- **네트워크를 통해, 복수의 컴퓨터에서 리소스를 공유 가능하다.**
- 리소스의 공유를 통해 컴퓨터 한 대로는 불가능했던 일이 가능해짐.
  - 예를 들어, 네트워크가 없는 상태에서는 PC 마다 프린터를 연결해야했음. 
    - 👉네트워크가 있으면 공유하고 있는 프린터에서 인쇄할 수 있으므로 프린터는 한 대면 됨
      - PC에서는 프린터가 직접 연결된 것은 아니지만, **네트워크로 공유되는 프린터 사용**
- 리소스 공유 방법?
  - 데이터 통신으로 컴퓨터가 가진 리소스를 서로 주고받음으로써 공유

> _**리소스**_
> - 메일, 파일, 데이터 등 컴퓨터랑 사용자가 가진 것
> - 컴퓨터나 사용자가 갖는 물리적, 논리적을 따지지 않는 '자원'
>   - 사용자가 가진 지식, 기능
>   - 컴퓨터의 하드웨어(CPU, 메모리, 하드디스크 등)
