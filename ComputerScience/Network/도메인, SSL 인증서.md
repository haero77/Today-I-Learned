# 도메인(Domain) 🏠

- 도메인은 쉽게 말해 웹사이트의 '주소'.
- 우리가 google.com이나 naver.com을 주소창에 입력해 접속하는 것처럼, 숫자로 된 복잡한 IP 주소(예: 172.217.175.78)를 사람이 기억하기 쉬운 문자로 바꿔준 것.

# SSL 인증서 💳

- SSL 인증서는 해당 웹사이트가 '신뢰할 수 있고 안전하다'는 것을 증명하는 **'신분증'**.
  - 신원 확인, 데이터 암호화 라는 두 가지 역할을 수행.

- 비유: 집주인의 신분증 또는 등기부등본과 같습니다. 이 집이 정말 '홍길동'의 집이 맞는지 신분증으로 확인하고, 중요한 대화(데이터)는 우리 둘만 알아볼 수 있는 암호로 나누는 것과 비슷.
- SSL 인증서가 적용된 사이트는 주소창에 http가 아닌 `https://`로 표시되고, 자물쇠(🔒) 아이콘이 나타난다.
    
## 신원 확인

- 신원 확인: 현재 접속한 사이트가 진짜 그 사이트가 맞는지 확인해준다. 
- 예를 들어, mybank.com에 접속했을 때, 해커가 만든 가짜 mybank.com이 아니라 실제 은행 사이트임을 보증.

## 데이터 암호화

- 데이터 암호화: 사용자가 웹사이트와 주고받는 모든 정보를 암호로 바꿉니다. 만약 누군가 중간에서 데이터를 훔쳐보더라도, 암호화되어 있어 무슨 내용인지 알 수 없게 만듭니다. 
- 로그인 정보, 비밀번호, 개인정보 등을 안전하게 보호하는 핵심 역할.
