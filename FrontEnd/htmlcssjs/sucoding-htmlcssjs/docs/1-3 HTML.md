# 2. HTML 문서 작성을 위한 기본 내용 살펴보기

## 2.1 HTML 기본 구성 요소

### 태그

```html
<태그명>
```

- 구성 요소 정의
- HTML 문법을 이루는 가장 작은 단위

### 속성

```html
<태그명 속성명="속성값">
<html lang="ko">
```

- 태그에 어떤 의미나 기능 보충.
- 속성명: 따옴표 없음, 
- 속성값: 큰따옴표로 작성, 속성값 여러 개인 경우 쉽표로 구분.

### 문법 

- HTML은 태그와 속성으로 문법 구성됨
- 문법은 콘텐츠 있는 문법, 없는 문법으로 나뉨

콘텐츠 있는 문법

```html
<태그명 속성명="속성값">콘텐츠</태그명> <!-- 요소 -->
<title>Hello world!</title>
```

- 태그, 종료 태그, 콘텐츠를 합쳐서 요소(element)라고 함.

콘텐츠 없는 문법 = 빈 태그

```html
<br>
```

### 주석

```html
<!-- 주석 내용 -->
```


## 2.2 HTML의 기본 구조

- `<!DOCTYPE html>`: DTD - 문서형 정의
- `<html>`: HTML 문서의 시작과 끝
- `<head>`: 문서 정보 정의
- `<body>`: 웹 브라우저에 표시할 내용

## 2.3 HTML의 특징 파악하기 

### 2.3.1 블록 요소와 인라인 요소

- 공간 유무와 관계 없이 p 태그 처럼 사용할 때마다 줄바꿈되는 태그 있음.
  - 이런 태그로 작성한 요소를 블록 요소(block element)라고 함.
- a, span 태그 처럼 줄바꿈 없이 작성되는 태그 있음.
  - 이런 태그로 작성한 요소를 인라인 요소(inline element)라고 함.
